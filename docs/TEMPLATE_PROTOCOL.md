## 4. 评估协议

- 划分：`<例：5×2 分层交叉验证>`，`StratifiedKFold(shuffle=True, random_state=seed+rep)`
- 种子规则：折划分 `seed+rep`；采样/增广 `seed*1000+rep*10+fold`；模型 `seed+rep`
- 指标：`<AUC / PR-AUC / F1-minority / G-mean / Brier / RMSE …>`，同时报均值与标准差
- **禁止泄漏**：任何依赖标签或全体分布的变换（重采样、目标编码、特征选择）只能在训练折内做
- 统计检验：多数据集比较用单侧 Wilcoxon signed-rank + 胜负计数

## 5. 等价判据（复现"算成功"的定义）

对每条主张 C1–Cn，同时满足才算复现成功：

1. **方向一致**：差异符号与原文相同；
2. **排序一致**：方法间的相对优劣顺序一致（Spearman ρ > 0 即可，不要求完全一致）；
3. **幅度容忍**：`|Δ| ≤ 0.02`（指标为准确率/AUC 类）或按原文噪声水平设定阈值。

不满足时：先查偏离清单 → 再做敏感性分析（如第一轮发现剪枝强度会翻转结论）→ 最后写成"未能复现 + 原因假设"，
这本身是可接受且有价值的结论。

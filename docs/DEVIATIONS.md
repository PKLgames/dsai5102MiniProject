# DEVIATIONS ｜ 与论文的偏离清单

> owner: A ｜ 每条都是“我们与原文的差异 + 为什么 + 对结论的影响”，报告 Methodology/Discussion 直接引用。
> 论文：Chawla et al., *SMOTE*, JAIR 16 (2002) 321–357

| # | 偏离 | 原因 | 对结论的影响 | 状态 |
|---|---|---|---|---|
| D1 | 用 `DecisionTree(criterion="entropy")` 代替 C4.5 release 8 | C4.5 非开源且 1990s 二进制不可得 | 同为熵准则；CART 为二叉树、无 C4.5 的剪枝与多叉分裂 → 绝对 AUC 有系统偏移，故用“方向 + 排序”判定等价 | 已生效 |
| D2 | 10-fold 单次 CV → 5×2 分层 CV | 单次折方差大，无法给置信区间 | 均值更稳、std 可用；比较不变 | 已生效 |
| D3 | E-state（53,220×~200，8.4:1）未复现，改用 `qsar-biodeg`(1,055×41) | 该数据由 Tripos 生成、属 NCI 筛选私有产物，无公开镜像 | 失去“高维化学信息学”这一格；用 `yeast`/KDDCup99 子集补“中大样本”格 | 待 B 确认 |
| D4 | Can（443,872×~30，52:1）未复现，改用 KDDCup99 10%（494,021×41） | 该数据由 AVATAR/Mustafa 可视化工具生成，属内部产物 | **Can 行的绝对 AUC 不可比**，只比方向与相对提升；报告中该行标注 `(substitute)` | 待 B 确认 |
| D5 | 论文固定 k=5，我们额外扫 k∈{1,3,5,10} | k 敏感性在原论文中未做 | 属我们的扩展，报告中明确标注“非论文主张” | 计划 |
| D6 | 增加 RandomForest / LogisticRegression | 检验结论是否只依赖树模型 | 增强稳健性，不改变 C1–C3 判定口径 | 计划 |
| D7 | 论文的 AUC 是“扫过整条 ROC 曲线”的整体 AUC；我们对每个配置算单点 AUC | 论文的点是 (过采样百分比, 降采样百分比) 组合的扫描，重建全部组合成本高 | 我们以“同配置对比 + 方向一致”判定，不追求单点数值等于 7242 之类的表格值 | 已生效 |
| D8 | 未复现 Ripper 与 Naive Bayes 的 loss-ratio / prior 扫描 | Ripper 无 Python 等价实现；NB 的 prior 扫描与主结论无关 | C1 只用 C4.5 代理判定，Ripper/NB 曲线作为论文背景介绍 | 已生效 |

| D9 | C4.5 代理用“CART + 熵 + 训练折内 CCP 剪枝”（`src/learners.py::PrunedDecisionTree`） | 未剪枝 CART 在 Pima 上只有 0.673 AUC（论文 0.7242），明显欠拟合于 C4.5 的剪枝行为 | 剪枝强度由内层 3 折 CV 在训练折内选，不接触测试折；对 Pima 的 SMOTE-vs-RUS 排序有实质影响（见 D10） | 已生效 |
| D10 | 主判据对“树代理的剪枝强度”敏感：Pima 上 `dt_raw`/`dt_msl5` 下 RUS 胜过 SMOTE，`dt`（CCP）下 SMOTE(200%) 胜过 RUS | 论文只报 C4.5 一种树，我们无法完全复刻其剪枝与多叉分裂 | 因此 C1 不能用单数据集判定，必须用 8 数据集的胜负计数 + Wilcoxon；报告中给出三档剪枝的敏感性表 | 已生效 |
| D11 | satimage 用 OpenML did=182（6430×36），论文为 6435 例、少数类 626 | OpenML 版本与论文数据版本不同，无更原始镜像 | 差异 5 例（0.08%），不影响方向性结论，标注在表格脚注 | 已生效 |
| D12 | `rus{N}` 表示“保留多数类原数量的 N%”，`rus` = 降采样到 1:1 | 论文的降采样是 10%–2000% 的率扫描，单一 1:1 点无法代表“Under”列 | 主网格里 `rus` 仅作为 1:1 参考点；C1 的“Under 列”取 `rus{25,50,100}` 中的最佳者（脚本 `scripts/best_under.py` 待补） | 计划 |

## 记录规范

- 新增偏离：追加一行，写清“是什么 / 为什么 / 影响哪个主张 / 影响多大”；
- 任何影响 C1–C3 判定的偏离，必须同时更新 `docs/PROTOCOL.md`；
- 实验脚本里对应的硬编码要有注释指回本条编号（如 `# D1: C4.5 proxy`）。
